# Муха

Настольная игра для 2--4 игроков.

## Цель игры

У каждого игрока есть 4 фишки.

Чтобы победить, нужно первым:

1.  вывести все свои фишки на поле;
2.  провести каждую фишку полный круг;
3.  завести все 4 фишки в свой дом.

Игра заканчивается, как только один из игроков разместил все свои фишки
в доме.

## Начало игры

Каждый игрок выбирает цвет и получает 4 фишки. До выхода на поле фишки
находятся за его пределами.

Чтобы определить, кто ходит первым, каждый игрок бросает один кубик.
Начинает игрок с наибольшим результатом. При ничьей претенденты
перебрасывают кубик.

Далее игроки ходят по очереди.

## Ход игрока

В свой ход игрок бросает два обычных шестигранных кубика.

Выпавшие значения разыгрываются отдельно, начиная с **большего**.

Например, если выпало `5 + 3`, сначала разыгрывается 5, затем 3.

Если для текущего значения есть допустимый ход, игрок обязан его
сделать. Если вариантов несколько, можно выбрать любой.

Если сделать ход невозможно, значение сгорает.

Оба значения можно использовать для разных фишек или последовательно для
одной и той же.

### Дубль

Если на обоих кубиках выпало одинаковое значение, игрок получает
**четыре хода** с этим значением вместо двух.

Например:

`3 + 3` даёт четыре хода по 3.

Ходы можно распределять между разными фишками. Игрок должен использовать
максимально возможное количество ходов; те, которые выполнить
невозможно, сгорают.

## Выход на поле

Чтобы ввести новую фишку в игру, нужно использовать `6`.

Фишка появляется на стартовой клетке игрока. Использованная шестёрка на
этом считается разыгранной.

Если осталось значение второго кубика, его можно сразу использовать ---
в том числе для только что вышедшей фишки.

## Движение по полю

Фишки движутся по часовой стрелке.

Значение кубика показывает точное количество клеток, которое должна
пройти выбранная фишка.

Нельзя перепрыгивать через другие фишки --- ни свои, ни чужие.

На одной обычной клетке может находиться только одна фишка.

Если пройти ровно выпавшее количество клеток невозможно, такой ход
сделать нельзя.

## Съедание

Если фишка заканчивает движение на клетке, занятой фишкой соперника,
фишка соперника считается съеденной.

Съеденная фишка отправляется на **солнышко** в центре поля.

За съедание дополнительный ход или другой бонус не даётся.

### Возвращение съеденной фишки

Чтобы вернуть фишку с солнышка, нужно использовать `6`.

После этого фишка возвращается за пределы поля. Чтобы снова ввести её в
игру, потребуется ещё одна `6`.

Таким образом, съеденной фишке нужны две шестёрки:

1.  одна --- чтобы уйти с солнышка;
2.  ещё одна --- чтобы снова выйти на поле.

Получить их можно в разные ходы.

Если шестёрку можно использовать несколькими способами, игрок сам
выбирает: передвинуть фишку на поле, вывести новую или вернуть
съеденную.

## Радуга

В каждом углу поля есть радуга, соединяющая две клетки.

Если фишка **заканчивает ход** на одном конце радуги, она автоматически
переносится на другой.

Радуга работает в обе стороны: она может как продвинуть фишку вперёд,
так и отбросить назад.

Если фишка просто проходит через клетку под радугой, ничего не
происходит.

Если конец обычного движения занят своей фишкой, действие недоступно и
телепорт не начинается.

После телепорта ход этого кубика заканчивается.

На клетке назначения действуют обычные правила: чужая фишка съедается, а
своя блокирует телепорт.

## Болото

В каждом углу поля находится болото из трёх клеток.

Если фишка заканчивает обычное движение на входе в болото, она
автоматически переходит на первую клетку болота. Отказаться от входа
нельзя.

Внутри болота действуют особые правила движения:

-   чтобы перейти с первой клетки на вторую, нужно выбросить `1`;
-   со второй на третью --- `3`;
-   чтобы выйти из болота --- `6`.

Во всех случаях фишка перемещается только на **одну клетку**.

### Толкание в болоте

В болоте фишки не блокируют друг друга.

Если следующая клетка занята, движущаяся фишка проталкивает стоящую там
фишку на следующую клетку. Если и она занята, возникает цепочка
толканий.

Толкать можно как свои, так и чужие фишки.

Внутри болота фишки не съедают друг друга.

Как только фишка выходит из болота, снова начинают действовать обычные
правила. Если на клетке выхода стоит чужая фишка, она съедается. Если
там находится своя фишка, выход заблокирован.

## Дом

После полного круга фишка проходит через свою стартовую клетку и вместо
следующего круга направляется в свой дом.

В доме четыре клетки --- по одной для каждой фишки.

Фишки продолжают двигаться по значениям кубиков, и перепрыгивать через
уже находящиеся в доме фишки нельзя. Поэтому первые пришедшие фишки
нужно продвигать как можно глубже.

Для движения необходимо точное значение. Если фишка не может пройти всё
выпавшее количество клеток, этот ход для неё недоступен.

Чужие фишки не могут заходить в дом другого игрока или съедать
находящиеся там фишки.

Когда фишка занимает своё окончательное место, её путь завершён и она
больше не двигается.

## Победа

Побеждает первый игрок, который полностью заполнит свой дом всеми
четырьмя фишками.

Партия заканчивается сразу после его победы.
