# Муха

Настольная игра для 2-4 игроков.

## Цель игры

1. Завести все свои фишки в игру,
2. Провести фишки через поле,
3. Завести все фишки в дом.


## Начало игры

Каждый игрок выбирает цвет и получает 4 фишки.

Чтобы определить, кто ходит первым, каждый игрок бросает один кубик.
Начинает игрок с наибольшим результатом.
При ничьей претенденты перебрасывают кубик.

Кубики определяют только первого игрока.
После него остальные игроки ходят по часовой стрелке в соответствии со своим расположением вокруг поля.
Затем этот порядок повторяется до конца партии.

До выхода на поле фишки находятся за его пределами.

## Ход игрока

В свой ход игрок бросает два шестигранных кубика.

Выпавшие значения могут разыгрываться отдельно, всегда начиная с **большего**.

Например, если выпало `5 + 3`, сначала разыгрывается 5, затем 3.

Оба значения можно использовать для разных фишек или последовательно для одной и той же.

Если для текущего значения есть допустимый ход, игрок обязан его сделать.
Если есть несколько вариантов хода, нужно выбрать тот, который позволяет использовать как можно больше выпавших значений.
Если вариантов несколько, можно выбрать любой.
Если сделать ход невозможно, значение сгорает.


### Дубль

Если на обоих кубиках выпало одинаковое значение, игрок получает **четыре хода** с этим значением вместо двух.

Например: `3 + 3` даёт четыре хода по 3.


## Выход на поле

Чтобы ввести новую фишку в игру, нужно выбросить `6` хотя бы на одном кубике.

Когда игрок использует `6` для ввода фишки на поле, фишка появляется на стартовой клетке игрока перед домом.
Использованная `6` на этом считается разыгранной.

Если осталось значение второго кубика, его можно сразу использовать, в том числе для только что вышедшей фишки.

## Движение по полю

Фишки движутся по часовой стрелке.

Значение кубика показывает точное количество клеток, которое должна пройти выбранная фишка.

- Нельзя перепрыгивать через другие фишки - ни свои, ни чужие.
- На одной клетке может находиться только одна фишка.
- Если пройти ровно выпавшее количество клеток невозможно, такой ход сделать нельзя.

## Съедание

Если фишка заканчивает движение на клетке, занятой фишкой соперника, фишка соперника считается съеденной.

Съеденная фишка отправляется на **солнышко** в центре поля.

### Возвращение съеденной фишки

Чтобы вернуть фишку с солнышка, нужно использовать `6`.

После этого фишка возвращается слоты за пределами поля.
Чтобы снова ввести её в игру, потребуется ещё одна `6`.

Таким образом, съеденной фишке нужны две шестёрки:

1.  одна - чтобы уйти с солнышка;
2.  ещё одна - чтобы снова выйти на поле.

Получить их можно в разные ходы.

Если шестёрку можно использовать несколькими способами, игрок сам выбирает:
- передвинуть фишку на поле,
- вывести новую,
- вернуть съеденную.

## Радуга

В каждом углу поля есть радуга, соединяющая две клетки.
Радуга работает в обе стороны: она может как продвинуть фишку вперёд, так и отбросить назад.

- Если фишка **заканчивает ход** на одном конце радуги, она автоматически переносится на другой.
- Если фишка просто проходит через клетку под радугой, перемещение по радуге не происходит.
- Если начало или конец радуги занят фишкой, то:
1. чужая фишка съедается, 
2. своя фишка блокирует телепорт.

После телепорта ход этого кубика заканчивается.

## Болото

В каждом углу поля находится болото из трёх клеток.

Если фишка заканчивает движение на входе в болото, она автоматически переходит на первую клетку болота.
Отказаться от входа в болото нельзя.

Внутри болота действуют особые правила движения:
- чтобы перейти с первой клетки на вторую, нужно выбросить `1`;
- со второй на третью - `3`;
- чтобы выйти из болота - `6`.

Во всех случаях фишка перемещается только на **одну клетку**.

### Толкание в болоте

Внутри болота фишки не съедают и не блокируют друг друга.
- Если следующая клетка занята, движущаяся фишка проталкивает стоящую там фишку на следующую клетку.
- Если и она занята, возникает цепочка толканий.

Толкать можно как свои, так и чужие фишки.

Как только фишка выходит из болота, снова начинают действовать обычные правила.
- Если на клетке выхода стоит чужая фишка, она съедается.
- Если там находится своя фишка, выход заблокирован.

## Дом

После полного круга фишка проходит через свою стартовую клетку и вместо следующего круга направляется в свой дом.

В доме четыре клетки - по одной для каждой фишки.

Для движения необходимо точное значение.
Если фишка не может пройти всё выпавшее количество клеток, этот ход для неё недоступен.

Чужие фишки не могут заходить в дом другого игрока или съедать находящиеся там фишки.

Когда фишка занимает своё окончательное место, её путь завершён и она больше не двигается.

## Победа

Побеждает первый игрок, который полностью заполнит свой дом всеми четырьмя фишками.
